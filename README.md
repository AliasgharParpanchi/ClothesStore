# ClothesStore

## توضیحات پروژه
ClothesStore یک فروشگاه آنلاین پوشاک است که برای مدیریت موجودی کالا، دسته‌بندی محصولات، مدیریت کاربران و ثبت سفارش طراحی شده است. این نسخه از پروژه با معماری full-stack پیاده‌سازی شده است: بخش بک‌اند با Node.js و Express و دیتابیس MongoDB و بخش فرانت‌اند با React ساخته شده است. لایه داده به صورت جداگانه طراحی شده تا در پروژه‌های دیگر نیز قابل استفاده باشد و برای مدیریت تراکنش‌ها و عملیات داده‌ای از الگوهای مناسب استفاده شده است.

## قابلیت‌های اصلی
- مدیریت موجودی کالا (افزودن، ویرایش، حذف، مقدار موجودی)
- دسته‌بندی محصولات و فیلتر بر اساس دسته‌ها
- ثبت‌نام و ورود کاربران با سطوح دسترسی (ادمین و کاربر معمولی)
- ثبت سفارش و مدیریت سفارش‌ها
- نمایش آمار فروش یا موجودی با استفاده از نمودارها (در صورت پیاده‌سازی در فرانت‌اند)
- معماری لایه‌ای با لایه داده مجزا و امکان استفاده مجدد

## فناوری‌ها و ابزارها
- Backend:
  - Node.js
  - Express
  - MongoDB (با Mongoose)
- Frontend:
  - React
  - HTML, CSS, Bootstrap
  - JavaScript, Axios (یا Fetch) برای فراخوانی API
  - Chart.js (در صورت نیاز به نمودار)
- سایر:
  - JWT برای احراز هویت (در صورت پیاده‌سازی)
  - multer یا معادل برای آپلود فایل (تصاویر محصولات)
  - dotenv برای مدیریت متغیرهای محیطی

## پیش‌نیازها
- Node.js (نسخهٔ پیشنهادی: 14+ یا نسخه‌ای که در پروژه تنظیم شده)
- MongoDB (محلی یا سرویس ابری مانند Atlas)
- npm یا yarn
- برای اجرای فرانت‌اند: مرورگر مدرن

## راه‌اندازی و اجرا
1. مخزن را کلون کنید:
   git clone https://github.com/AliasgharParpanchi/ClothesStore.git
2. به پوشهٔ سرور (backend) بروید و پکیج‌ها را نصب کنید:
   cd api
   npm install
3. به پوشهٔ کلاینت (frontend) بروید و پکیج‌ها را نصب کنید:
   cd ../client
   npm install
   cd ../admin
   npm install
5. فایل تنظیمات محیطی (.env) را در پوشه سرور ایجاد کنید و متغیرهای مورد نیاز را اضافه کنید (نمونه):
   - MONGO_URI=<آدرس_MongoDB>
   - JWT_SECRET=<یک_کلید_محرمانه>
   - PORT=5000
6. سرور را اجرا کنید:
   cd api
   npm run dev
7. فرانت‌اند را اجرا کنید:
   cd ../client
   npm start
8. وارد صفحهٔ ثبت‌نام شوید و یک حساب کاربری بسازید. برای دسترسی مدیریتی، کاربر را در دیتابیس MongoDB به نقش admin تغییر دهید (مستندات یا collection مربوط به users را بررسی کنید).

توجه: اگر از MongoDB Atlas استفاده می‌کنید مطمئن شوید IP و کلید اتصال (connection string) به درستی تنظیم شده است.

## نحوه استفاده
- برای دسترسی به ادمین فایل database را در دیتابیس خود وارد کنید.
- با کاربر عادی می‌توانید محصول به سبد اضافه کرده و سفارش ثبت کنید.
- برای آپلود تصاویر محصولات از روت‌هایی استفاده کنید که در سرور برای دریافت multipart/form-data پیاده‌سازی شده‌اند.

## ساختار پیشنهادی پروژه
- /api
  - /models (Mongoose schemas)
  - /routes (API endpoints)
  - /controllers (منطق کسب‌وکار)
  - /middleware (احراز هویت، آپلود، لاگ و ...)
  - /config (اتصال به دیتابیس، متغیرهای محیطی)
- /client or admin
  - /src/components
  - /src/pages
  - /src/services (تعامل با API)
  - /src/utils
- /docs (در صورت نیاز به مستندات اضافی)

## نکات امنیتی و عملیاتی
- مقادیر حساس (مانند connection string و JWT secret) را در فایل .env یا سرویس مدیریت اسرار نگهداری کنید و هرگز آن را به مخزن اضافه نکنید.
- برای تولید در محیط واقعی از HTTPS، CORS محدود و تنظیمات امنیتی Express استفاده کنید.
- در صورتی که فایل‌های تصویری روی سرور ذخیره می‌شوند، محدودیت حجم و نوع فایل را اعمال کنید یا از سرویس‌های ذخیره‌سازی ابری استفاده کنید.
